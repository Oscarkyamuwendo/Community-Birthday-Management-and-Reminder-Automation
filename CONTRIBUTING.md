# Contributing

Thank you for considering a contribution. Useful contributions include bug reports, clearer setup instructions, date-handling improvements, and documentation updates.

## Before opening an issue

- Search existing issues to avoid duplicates.
- Describe the expected behavior and what happened instead.
- Include the relevant function name and sanitized error text.
- Use synthetic examples only. Never include real member names, birth dates, email addresses, or private Google IDs.

## Pull requests

1. Explain the problem and the proposed change.
2. Keep changes focused and document any configuration or spreadsheet-column changes.
3. Do not include secrets, production IDs, personal information, or exported real-world data.
4. Describe how the change was reviewed. Do not claim it was tested in a live Google Workspace environment unless it actually was.
5. Update the README when setup steps, expected form fields, columns, or triggers change.

## Scope

This project is a Google Apps Script example. Changes should preserve clear setup instructions, avoid duplicate birthday events where practical, and treat personal data carefully.
