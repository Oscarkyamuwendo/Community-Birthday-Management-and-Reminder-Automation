# Community Birthday Management and Reminder Automation

A Google Apps Script project that integrates Google Forms, Google Sheets, and Google Calendar to streamline birthday management for a community or small organization.

## The problem

Managing birthdays manually can involve repeated data entry, creating calendar events, tracking reminders, and checking for duplicate records.

## The solution

This project automates key parts of that workflow through Google Workspace integrations.

## Key features

- Processes birthday submissions from Google Forms.
- Creates recurring annual all-day birthday events in Google Calendar.
- Associates calendar events with spreadsheet records.
- Includes logic to help prevent duplicate events.
- Supports manual birthday entry and synchronization workflows.
- Sends scheduled email reminders.
- Tracks reminder status in the spreadsheet.

## Technology stack

- JavaScript
- Google Apps Script
- Google Forms
- Google Sheets
- Google Calendar

## Project goals

- Reduce repetitive administrative work.
- Improve consistency between spreadsheet records and calendar events.
- Make birthday reminders easier to manage.
- Document the workflow so others can review and adapt it.
