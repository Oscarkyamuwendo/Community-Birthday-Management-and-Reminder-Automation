# Code of Conduct

## Our pledge

Participation in this project should be respectful, constructive, and welcoming to people with different backgrounds and levels of experience.

## Expected behavior

- Be respectful and assume good intent.
- Give actionable feedback about code and documentation.
- Accept constructive criticism professionally.
- Protect other people’s privacy.

## Unacceptable behavior

Harassment, insults, discrimination, doxxing, publishing private information, or other hostile conduct is not acceptable.

## Enforcement

Project maintainers may edit or remove contributions that violate this code and may restrict participation when necessary.
